# Data Directory Overview

This directory houses raw, processed, and ground-truth labelled material catalogues across enterprises.

## Subdirectories:

1. `data/raw/`:
   - Contains immutable copies of original catalogue exports (e.g. CSV, JSON, XLSX).
   - Never edit raw files directly.
   - Files are git-ignored by default to prevent leaking proprietary or large files.

2. `data/processed/`:
   - Contains standardised, cleaned data generated by `src/preprocess.py`.
   - Attributes extracted: normal text, standard units, normalized dimensions, material grade, and clean tokens.

3. `data/labelled/`:
   - Contains labelled pair datasets used for training and evaluating entity resolution models.
   - Standard schema:
     - `record_id_1`: Unique identifier of first record
     - `record_id_2`: Unique identifier of second record
     - `label`: Binary (1 = functionally equivalent match, 0 = non-match)
     - `match_type`: Exact, functional equivalent, distinct specification
     - `ground_truth_cluster_id`: Canonical cluster identifier for purity evaluation
     - `notes`: Justification or provenance of labelling

## Integrity Rule:
No synthetic or fabricated datasets are to be committed. All ground truth must document its source and annotation methodology.
